# RE6 实时差分管理器

适用于 Steam PC 版《生化危机 6》的游戏内差分管理器。将同一个模型的部件显隐保存为分组预设，在游戏中即时切换。插件通过 Direct3D 9 控制子网格的绘制，按材质归类，也支持逐个子网格调整。

## 安装

1. 从 [Releases](https://github.com/daoity/RE6-Variant-Manager/releases/latest) 下载 `RE6-Variant-Manager-v0.3.2.zip`。
2. 退出游戏，在 Fluffy Mod Manager 中停用旧版 RE6 实时差分管理器以及其它提供 `d3d9.dll` 的 Mod。将 ZIP 导入 Fluffy，刷新列表并启用 **RE6 Variant Manager**。
3. 启动游戏，进入角色可见的场景，按 **F3** 打开面板。顶部下拉框列出当前检测到的模型。

安装使用 Releases 中的独立 ZIP 附件。GitHub 自动生成的仓库归档包含说明和许可文件。

## 使用

- 选择模型和分组，按材质或子网格调整显隐。材质显示为 `MAT_…` 时，可用旁边的「预览」定位部件，再右键名称添加备注。
- 点击「保存新预设」。勾选「勾选全部部件」后，保存并显示当前分组的全部部件。留空则保存当前显隐。
- **F1** 切到上一个预设，**F2** 切到下一个预设，按预设栏的编号循环。选中的模型仍在画面中时，关掉面板也可以切换。**Shift + F2** 恢复所有模型的部件显示。
- 模型从列表消失时，按 **F3 → 重新读取**。插件会重扫角色资源并重新匹配当前画面。扫描可能短暂停顿，成功后会重置临时显隐和预览，已保存的预设与备注可重新载入。

### 自定义血量预设

血量差分默认关闭。保存预设后，在当前模型和分组的「血量切换」中增删 **0%–99%** 的整数阈值。每档可选择一个预设或「保持当前」。打开面板顶部的「启用血量差分」后，掉血和回血都会按到达的档位切换。例如阈值设为 20%、45%、75%，到达 32% 就用 45% 档。血量超过最高阈值时，应用指定的默认预设，或恢复自动切换前的穿着。添加 0% 可单独处理归零。旧版 25%、50% 和恢复默认绑定会自动迁移。

### 头部预设

按 **F3 → 头部预设**，从下拉框选择当前画面里识别到的独立头部。每个头部模型都有自己的分组和预设，可按材质或子网格调整显隐后保存。**F1 / F2** 循环切换当前页面所选模型与分组的预设。

独立过场模型标记为「过场头部」。与身体共用同一模型的头部部件，可在「普通模型」页按实际拆分的子网格调整。

预设和备注保存在 `%LOCALAPPDATA%\RE6VariantManager`。Mod 作者可将 Blender RE6 Model Editor 生成的材质名缓存随 Mod 分发，放在 `RE6VariantManager/MaterialNames/<mod-name>.json`。

## 兼容范围

插件识别受支持的 MOD211 模型、索引数据和绘制调用。能切换的部件取决于已加载模型的网格拆分和绘制方式，血量功能需要匹配受支持的 `BH6.exe`。

同一模型的等效副本会合并，包括材质槽位顺序不同、但每个子网格引用的材质一致的副本。共用索引的副本存在差异时，插件优先使用唯一可判定的角色专用 ARC 候选，仍无法区分的冲突会跳过。如果场景同时绘制共用索引和绘制范围的副本，显隐可能同时作用于两份。

0.3.2 已通过独立 Direct3D 9 测试，覆盖 Leon 头部、Ada 身体和手部、Chris 头部、模型热重读以及自定义血量预设。实际战役和联机兼容性仍待验证。
