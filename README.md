# RE6 实时差分管理器 v1.0

适用于 Steam PC 版《生化危机 6》的游戏内差分管理器。将模型的部件显隐保存为分组预设，在游戏中即时切换，也可以按本地主角血量自动切换。支持普通模型、独立头部、随机溶解和作者自定义遮罩与发光贴图。

## 安装

1. 从 [最新正式版](https://github.com/daoity/RE6-Variant-Manager/releases/latest) 下载独立附件 `RE6-Variant-Manager-v1.0.0.zip`。
2. 退出 RE6，在 Fluffy Mod Manager 中停用旧版管理器和其他提供 `d3d9.dll` 的 Mod。
3. 将 ZIP 导入 Fluffy，刷新列表，启用英文名称 **RE6 Variant Manager**。
4. 启动游戏，进入角色可见的场景，按 F3 打开面板。

安装包包含插件、说明和第三方许可。已有预设、分组和备注保存在 `%LOCALAPPDATA%\RE6VariantManager`，安装新版后会继续读取。GitHub 仓库页面提供说明文件，发行版附件用于安装。

## 使用

选择当前绘制的模型和分组，按材质或子网格调整显隐，再保存预设。「保存新预设」中的「勾选全部部件」用于保存并显示当前分组的全部部件。留空时保存当前显隐状态。

材质显示为 `MAT_…` 时，用旁边的「预览」定位部件，右键名称添加备注。Mod 作者可以把 Blender RE6 Model Editor 导出的材质名缓存随包放在 `RE6VariantManager/MaterialNames/<mod-name>.json`。

独立头部在「头部预设」页选择和保存。与身体共用模型的头部部件，按实际网格拆分在「普通模型」页控制。检测掉出列表时，点「重新读取」重扫并匹配当前画面。扫描可能短暂停顿，成功后临时显隐与预览重置，磁盘上的预设和备注可继续载入。

## 快捷按键

- F3 打开或关闭面板。
- F1 / F2 按编号循环切换上一个或下一个预设。
- Shift + F2 恢复全部模型的部件显示。
- 小键盘 1–9 切换当前列表前九行，需打开面板并开启 Num Lock。

详细生效条件、头部页面切换和鼠标操作见 [独立快捷键说明](SHORTCUTS.zh-CN.md)。

## 血量预设

血量差分默认关闭。先保存预设，在当前模型和分组的血量设置里添加 0%–99% 的整数阈值，为每档绑定预设或「保持当前」，然后开启「启用血量差分」。

掉血和回血都按到达的档位切换。阈值为 20%、45%、75% 时，32% 血量使用 45% 档。超过最高阈值后，可应用指定默认预设，或恢复自动切换前的穿着。0% 可以作为独立档位。旧版固定阈值绑定会自动迁移。

## 溶解与特效

开启「启用溶解特效」后，切换有部件显隐差异的手动预设或血量预设即可播放过渡。时长可在 0.1–5.0 秒之间调整，默认 0.8 秒。方向默认为「同时溶解 · 随机」，也支持沿模型自身 X/Y 轴向四个方向推进。

开启「白热碎光与余烬」时，使用大小不一、边缘扭曲的不规则碎解，碎光和余烬跟随同一遮罩。关闭该项后使用细密渐隐。切换开关可直接作用于正在进行的过渡。

方向在兼容的模型坐标通道上跟随模型，转镜头后仍从模型同一侧开始。无法读取兼容坐标的通道使用随机碎解。发光在兼容的单目标彩色通道绘制。

## 自定义遮罩和特效贴图

在 F3 中开启溶解和「白热碎光与余烬」，按需要分别勾选「自定义遮罩」「自定义特效贴图」。以 BH6.exe 所在目录为起点，放入需要的文件。

| 文件 | 用途 |
| --- | --- |
| `RE6VariantManager/Effects/damage_mask.png` | 消失时的灰度遮罩 |
| `RE6VariantManager/Effects/restore_mask.png` | 显现时的灰度遮罩 |
| `RE6VariantManager/Effects/damage_effect.png` | 消失时的彩色发光 |
| `RE6VariantManager/Effects/restore_effect.png` | 显现时的彩色发光 |

遮罩按红色通道读取，消失时黑色最先、白色最后。特效 RGB 控制颜色，Alpha 控制强度。图片按切换部件的模型 X/Y 范围投射一次。PNG 单边最多 2048 像素，每张最大 16 MiB，建议从 512 × 512 开始。

导出 PNG 后点「重读自定义贴图」。面板会分别显示四个槽位的加载状态，缺图或读取失败的槽位使用内置效果。

完整的 Photoshop 手画遮罩、云彩混合、透明特效绘制、导出、验证与 Fluffy 打包流程见 [遮罩与特效贴图制作说明](Custom-Textures.zh-CN.md)。

## 兼容范围与验证

插件识别支持的 MOD211 模型、索引数据和绘制调用。可切换部件取决于已加载模型的网格拆分。血量读取需要匹配受支持的 BH6.exe。

等效模型副本会共享显隐设置，包括材质槽位不同但子网格实际引用材质一致的副本。共用索引出现冲突时，优先使用唯一可判定的角色专用 ARC 候选。仍有歧义的冲突会跳过，同时绘制相同索引和范围的副本可能一起受显隐影响。

当前渲染实现已通过独立 Direct3D 9 测试，覆盖模型识别、预设与血量切换、模型方向、效果开关、自定义 PNG、热重读和渲染状态恢复。战役中的具体 Mod、画面和联机组合仍需玩家实际验证。诊断日志在 `%TEMP%\RE6VariantManager.log`。
